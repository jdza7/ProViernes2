# Ubika — Sistema de Búsqueda de Productos en Trujillo

Plataforma web diseñada para conectar a los consumidores de Trujillo con negocios y tiendas locales, permitiéndoles buscar productos específicos, comparar opciones y ubicar establecimientos cercanos de forma rápida y directa.

## Características principales

* **Búsqueda rápida de productos:** Consulta de artículos por nombre, categoría o palabra clave en comercios de Trujillo.
* **Ubicación de negocios locales:** Visualización de tiendas disponibles, dirección y datos de contacto del establecimiento.
* **Gestión de catálogo para comercios:** Registro y administración de productos, precios y disponibilidad por negocio.
* **Interfaz adaptable (Responsive):** Navegación optimizada tanto para dispositivos móviles como para computadoras de escritorio.

## Tecnologías utilizadas

* **Backend:** PHP 8.x (PDO / MySQLi)
* **Base de datos:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Entorno local:** XAMPP / Apache
